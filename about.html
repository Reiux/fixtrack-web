IT-WS02 Web Systems Project

About FixTrack & Our Team

FixTrack is a repair tracking website we created for our IT-WS02 class. It lets customers check their repair progress online in real time and gives shop staff a clean dashboard to manage orders.

FixTrack (The System)

The Website Template

FixTrack is the core website template. We built it so any repair shop can rebrand it just by editing one settings file (config.js). It handles customer booking, generates unguessable ticket IDs, and prints receipts with QR codes without needing any database or backend server.

  • Runs completely in the browser using plain JavaScript
  • Easy to rebrand: change the shop name and contact info in config.js
  • Saves tickets in the browser so data isn't lost on refresh

Demo Repair Shop (Our Test Shop)

Sample Shop for Presentation

To test and demonstrate FixTrack for our presentation, we set up the site for "Demo Repair Shop", a fictional repair shop in Cabanatuan City that fixes smartphones, laptops, tablets, and smartwatches.

  • Handles walk-in repairs and courier drop-offs
  • Clear pricing breakdown for parts and labor in Philippine Peso (₱)
  • Includes -days warranty coverage on all replacement parts

Key Features We Built

Live 6-Stage Repair Tracker

Customers can follow their repair through 6 clear milestones from intake to pickup, complete with timestamped technician notes, estimated ready dates, and inspection badges.

Thermal Receipts & Mobile QR

Generates authentic 58mm/80mm thermal receipts with an embedded QR code that carries ticket state directly, allowing customers to scan and track on their phones without an external database.

Staff Workbench Console

A dedicated management dashboard where technicians can search and filter active tickets, update repair stages, assign lead technicians, and add diagnostic logs.

Itemized Billing Breakdown

Transparent line-item accounting for diagnostic fees, replacement parts, and bench labor, with automated VAT calculation and parts warranty coverage.

Secure Unguessable Ticket IDs

Every intake generates a high-entropy, non-sequential tracking ID (e.g. FIX-7K9P-4M2W) with over 656 billion combinations, protecting customer privacy.

1-File White-Label Rebranding

Any repair shop can rebrand the entire platform in minutes by editing a single configuration file (config.js) for shop info, pricing, VAT, and supported devices.
