About FixTrack & The Team

FixTrack is a front-end white-label repair tracking platform that empowers gadget repair shops with real-time customer transparency and workshop bench management.

FixTrack (The Platform)

Software Architecture & Core Engine

FixTrack acts as a turnkey SaaS template for repair shops. It provides an intake booking wizard, automated non-sequential ticket ID generation, offline canvas-based QR thermal printing, and a multi-stage status tracker with live cost breakdowns.

  • 100% Client-Side zero-backend dependency
  • Centralized white-label configuration (config.js)
  • Robust localStorage state with automatic cache versioning

Demo Repair Shop (The Pilot Client)

Fictional Case Study Implementation

To demonstrate the system under real-world conditions, the platform is configured for "Demo Repair Shop", a fictional electronics repair center in Cabanatuan City specializing in smartphones, laptops, tablets, and smartwatches.

  • Real-time intake for walk-in and courier drop-offs
  • Transparent parts & labor billing with Philippine Peso (₱)
  • -days parts warranty and inspection logs

Key Engineering Highlights

Untraceable Ticket IDs

Generates non-sequential IDs like FIX-7K9P-4M2W from over 656 billion combinations, eliminating guessable ID enumeration.

Thermal Print Engine

Generates offline receipts formatted for A5/A6 thermal printers with embedded QR tracking, dark-mode print protection, and zero duplicate canvases.

Apple-Style S/N Logic

Emulates Apple's modern 2021+ randomized 10-character serial number schema using cryptographically random values with ambiguous character exclusion.

6-Stage Milestone Sync

Staff actions in the workbench immediately reflect on the customer tracking view, dynamically rendering device images and timeline logs.
